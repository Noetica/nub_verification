What was learned

Login works end-to-end

Real admin login to Contoso took ~9 seconds. MSAL popup, TOTP, stay-signed-in prompt — the harness drives it all.

Data Import report is the blocker

After entering inputs and clicking View Report, the results grid (`.p-datatable-table-container`) never appeared. 30-second timeout. Test data is dated 2026-01-01 to 2026-05-31.

Shared session = cascading failures

One TOTP login (30-second window) is shared across all tests. A failure at report N leaves the browser stuck, blocking reports N+1 through N+12.

Failure evidence is captured

Each failed test produced trace.zip + page.png + console.log in TestResults/failures/. The evidence pipeline works.
